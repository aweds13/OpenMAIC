# taste · 技术品味与红线（品味层）

> **本层是什么**：五层里唯一允许主观的一层。它回答的不是「必须做到什么」（规格层）也不是「怎么验」（契约层），
> 而是**什么算好**——评审时说「这不是我想要的」到底指什么。
> 上游：能引用 `intention/needs.md` 的 N，但不强制。下游：不进 `check-layers.py` 的硬判据，进人的判断。
> 允许主观，但**每条必须给出可执行的判据**，否则就是废话。

---

## 一、这个项目是什么（一句话，决定了所有取舍）

OpenMAIC 是**把一节课做成可翻页的课件并保证它真的做得出来**的系统。
它不是幻灯片编辑器，不是课程市场，不是播放器 —— 它的核心价值在「**从一句话意图到一页可读内容**」这条路上不出假成功。

这条定位决定了下面所有的「宁可 X 也不 Y」。

---

## 二、产品品味

1. **宁可少一页，也不要一页读不完。** 密度是硬约束不是风格偏好。
   判据：任何一页的字号低于下限或内容溢出画布 → 拒绝写入，并给出「拆页」的建议，而不是压缩字号。

2. **宁可空着，也不要猜。** 没有当前页就说没有；检索没命中就说没找到；参数缺失就报缺。
   判据：任何工具的空态返回必须含一个能被人读懂的句子，不得返回 `{}` 或空数组。

3. **宁可慢一秒，也不要给一个错的。** 校验优先于流畅。
   判据：写库路径上宁可多一次回读，不得跳过写后自检。

4. **宁可多一步确认，也不要一个不可逆的默认。** 默认必须是最安全的那个选项。
   判据：改页面默认 `dryRun`，落盘要显式；删除要二次确认。

5. **宁可暴露难看的事实，也不要好看的空壳。** 失败要带原因，不能显示「加载失败」四个字。
   判据：错误文案必须含原始原因片段（如 `ECONNREFUSED 127.0.0.1:5433`）。

6. **宁可一套，也不要两套。** 同一个数据只有一个真源，同一个能力只有一个实现。
   判据：新增一份数据副本前，先证明原路不可用。

## 三、架构品味

1. **宿主可换，内容不换。** 渲染、数据、工具要能在 DSH 与浏览器两个宿主下用同一份实现。
   判据：换宿主时改的是「谁来调用」，不是「被调用的是什么」。

2. **渲染交给上游，别自绘近似版。** 近似版会随上游漂移，而漂移无声。
   判据：能用上游组件的地方，不写自己的 div 布局。

3. **闸在写之前，不在写之后。** 事后校验只能发现问题，不能防止问题。
   判据：任何写入都必须先过校验；校验失败整批不落盘。

4. **状态要有真源。** 进程内缓存可以，但不能当判据。
   判据：任何「现在是什么」的断言，都能用一条 SQL 复现。

5. **能力可选，缺失要显式。** 旁挂服务可有可无，缺了要让工具**不存在**，而不是「在但总失败」。
   判据：未配置的能力不出现在工具表里，提示词里也不出现它的名字。

6. **系统提示词逐字节稳定。** 一个空格的变化都会让缓存全失效。
   判据：改提示词后必须确认前缀哈希没变，或明确知道为什么值得变。

7. **一个概念一个词。** 「页」不叫「场景」也不叫「slide」混用。
   判据：新增术语前先查是否已有同义词。

## 四、工程品味

1. **契约先于实现。** 先写「怎样算做完」，再写代码。
   判据：没有 OP-x / FLOW-x 覆盖的操作，不动手。

2. **结论必须实测。** 不实测就写「不知道」，不写「应该是」。
   判据：任何结论后面跟一条命令或一个读数；跟不上的降级为假设。

3. **证据要能被别人复查。** 只写「已修复」不算证据。
   判据：证据必须含「跑什么命令、看到什么输出」。

4. **改动范围最小。** 优先加分支/开关，不重写。
   判据：一次改动超过 200 行，先问能不能拆。

5. **判据要能证明它看得到东西。** 一个永远绿的检查等于没有检查。
   判据：每个护栏必须打出「这次实际检查了几条」，并且喂过坏样例能红。

6. **文档跟着代码走，且分层。** 需求里不写文件名，实现里必须写文件名。
   判据：把一段文字拷到纸上合上电脑还成立 → 意图/规格层；开着编辑器才看得懂 → 实现层。

7. **不制造假红。** 环境问题要显式标注「本机环境、不修」，不许混进真红里。
   判据：红了的测试必须能归因到「代码 / 环境 / 上游」三者之一。

8. **宁可让代码给默认值，也不指望提示词约束。** 提示词管得住的话，照样要有一条代码兜底。
   判据：每一条「不要做 X」写进提示词时，必须同时有一个代码默认值让 X 做不到。
   实测反例：自学模式最早只写在提示词里（「不要跑 generate_actions」），可讲稿是
   `generate_scene` **内部**生成的 —— 162 次 `generate_scene` 对 160 次 `patch_stage`，
   79 个 slide 页 **100%** 都产出了动作（均 13.2 条），其中 36 次 patch 明写「移除自动生成的旁白」，
   等于每页白花一次模型调用再花一次删掉它。

9. **宁可先量，也不先优化。** 「感觉慢」不是读数。
   判据：动手前给出**分量读数**，而不是一个总分。实测「看课慢」的直觉是「数据太大」，
   真读数是最大课 428 kB、课程数据 API **0.03 秒**；慢的是 dev 模式一页挂 **91 个未打包 script**。

10. **宁可承认缓存治不了另一侧，也不拿缓存当万能药。**
    判据：说「有缓存了」之前必须先分清慢在哪一侧。实测 `turbopackFileSystemCacheForDev`
    默认 `true`，重启后首次 **0.46 秒**、真冷编译 **5.26 秒** —— 它治不了浏览器那侧的 91 个脚本。

11. **宁可为一个状态写清「它在哪条链上合法」，也不把它搬到别处复用。** 合法是**相对于链路**说的。
    判据：一个状态或常量被第二处引用时，必须**重新算量纲**。
    实测反例：空动作页在听课链里占一拍是对的（不占就会从播放里消失），
    搬到阅读里就变成「每页停 2 秒」，而 350–400 字要读 1–2 分钟 —— **差 30–60 倍**。

12. **宁可让编译器拦，也不指望人记得传。** 没有渲染测试兜底的地方，类型是最后一道闸。
    判据：一个「传了才生效」的可选参数必须有理由；**漏传只静默降级、不报错的，一律改成必填**。
    实测收益：`readingPage` 设成必填后，`tsc` 当场抓出 3 个漏传点，还顺带暴露了
    `CanvasArea` 自己在算这个值（于是 `CanvasAreaProps` 用 `Omit` 把它摘掉）。

## 五、红线（违反即打回，不讨论）

| 红线 | 为什么 |
|---|---|
| 不写「已修复」而没有读数 | 假绿灯比红灯更贵 —— 它会让人停止怀疑 |
| 不做无差别全仓字节替换 | 曾经因此静默损坏 54 个二进制文件 |
| 不在功能分支上指望 CI 触发 | `on.push.branches` 只含 `main`，分支上 0 check |
| 不把进程内状态当数据真源 | 重启即失，多进程即分裂 |
| 不用 `git add -A` | 会卷进不属于本项目的文件 |
| 不在文档里把「未实现」写成「已实现」 | 文档的唯一价值是可信 |

---

## 六、评审时怎么用这一层

- 有人问「为什么不直接上 X」→ 先看第二节有没有对应的「宁可」。
- 两条品味冲突时（如「宁可慢一秒」vs「一屏不淹没」）→ 按 **不可逆 > 正确性 > 密度 > 速度** 排。
- 品味层与规格层冲突 → **规格层赢**，然后回来改这一层（说明这条品味写错了）。
