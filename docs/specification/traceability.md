## 三、SR 目录（一行一条，正文在域文件里展开）

**F1 内容密度与页面形态**

| SR | 一句话 |
|---|---|
| SR-F1.1 | 每页内容必须在画布可视范围内完整呈现，不得依赖滚动或被裁切 |
| SR-F1.2 | 页面内容必须经由 Writing DSL 落成 canvas 元素，不得以纯文本/Markdown 直接投屏 |
| SR-F1.3 | 单页正文目标密度 350–400 汉字；低于目标必须补内容，不得留白 |
| SR-F1.4 | 内容超出单页容量时必须**加页**，不得压字号、不得删内容 |
| SR-F1.5 | 字号下限必须守住，不得为塞内容把 `fontSize` 压到可读阈值以下 |

**F2 阅读节奏与翻页**

| SR | 一句话 |
|---|---|
| SR-F2.1 | 阅读页不得有自动前进；下一页只由读者动作触发 |
| SR-F2.2 | 阅读页的停留时长不得被任何最小时长常量强制 |
| SR-F2.3 | 阅读页不得渲染无法生效的控件（播放/暂停/进度等） |
| SR-F2.4 | 滚轮、点击、方向键三种输入都必须能翻页 |
| SR-F2.5 | 翻页必须去抖，一次物理动作只翻一页 |
| SR-F2.6 | 滚轮翻页必须可关闭，且关闭后默认行为不被打断 |

**F3 自检页**

| SR | 一句话 |
|---|---|
| SR-F3.1 | 自检页题量必须可控传递，不得被下游写死 |
| SR-F3.2 | 题量不足必须显式报错，不得静默产出少题的页面 |
| SR-F3.3 | 自检页内容必须能被非交互读者读到（文本可抽取） |

**F4 批量导出**

| SR | 一句话 |
|---|---|
| SR-F4.1 | 多门课必须能一次导出为单个归档，不得要求逐课点击 |
| SR-F4.2 | 导出必须包含课件可用所需的全部资源，不得只是页面骨架 |
| SR-F4.3 | 导出必须报告每门课的成功/失败，不得整体静默 |

**F5 本地课程库检索**

| SR | 一句话 |
|---|---|
| SR-F5.1 | 检索必须支持按层级筛选（L0–L4），默认自动选层 |
| SR-F5.2 | 检索必须返回可点击定位的结构化命中，不得只回一段散文 |
| SR-F5.3 | 检索不得凭空编造条目；命中为空时必须明说没有 |
| SR-F5.4 | 命中后必须能把整篇文档读出来，不受预览上限约束 |
| SR-F5.5 | 取全文必须支持分页/续读，且必须给出续读指针或明说读完 |

**F6 真浏览器抓取**

| SR | 一句话 |
|---|---|
| SR-F6.1 | 抓取必须走真浏览器渲染，能拿到 JS 执行后的 DOM |
| SR-F6.2 | 抓取结果必须带可核查的来源标识（最终 URL、状态、耗时） |
| SR-F6.3 | 反爬/风控判定只允许作用于正文抽取，不得因裸词误伤整页 |
| SR-F6.4 | 「看」与「存」必须是两个动作，预览不得自动持久化 |
| SR-F6.5 | 预览必须有字数上限，正文抽取不受该上限约束 |

**F7 会话上下文与材料**

| SR | 一句话 |
|---|---|
| SR-F7.1 | 材料/画像的修改必须在下次会话生效，不得要求重启进程 |
| SR-F7.2 | 会话级材料内容不得写入系统提示词 |
| SR-F7.3 | 系统消息必须在同一会话内逐字节稳定（缓存友好） |
| SR-F7.4 | 原生压缩必须在预算触顶时真的发生，不得空转 |
| SR-F7.5 | 压缩预算必须按可用窗口配置，且必须大于固定开销 |

**F8 工具注册与提示词口径**

| SR | 一句话 |
|---|---|
| SR-F8.1 | 外部 MCP 连不上时必须只记录失败，不得注册其工具、不得阻塞会话 |
| SR-F8.2 | 未配置的能力不得注册工具 |
| SR-F8.3 | 未注册的工具名不得出现在提示词与允许表里 |
| SR-F8.4 | 同一能力在多处注册点必须同一口径（配置在则有，配置无则无） |

**F9 写入闸与版面差集**

| SR | 一句话 |
|---|---|
| SR-F9.1 | 写入前必须过闸；被闸拦下时必须给出「怎么解」而不是只报错 |
| SR-F9.2 | 一次写入必须整批原子：要么全成，要么一个都不写 |
| SR-F9.3 | 写入必须被独立校验，不得信任调用方自述 |
| SR-F9.4 | 状态必须能从数据库读回来核对，不得只信进程内状态 |
| SR-F9.5 | 自检结论必须指向可复查的落点（表/行/字段） |
| SR-F9.6 | 写入必须是 CAS：旧值不匹配就拒绝，不得覆盖他人改动 |
| SR-F9.7 | 写入必须默认只算差集、不落盘，落盘必须是显式选择 |

**F10 DSH 宿主与当前页**

| SR | 一句话 |
|---|---|
| SR-F10.1 | 课程列表、页列表、单页渲染必须在 DSH 内完成，不依赖旧 Web UI |
| SR-F10.2 | 课件渲染必须用上游 `SlideCanvas` 原生渲染，不得自绘近似版 |
| SR-F10.3 | 不得要求打开 Edge/外部浏览器来完成查看 |
| SR-F10.4 | 同一份数据只能有一个真源，DSH 与旧 UI 不得各存一份 |
| SR-F10.5 | 「当前页」必须在 UI 选中时立刻可被工具读到 |
| SR-F10.6 | 「当前页」缺失时必须明说没有，不得猜测或沿用上次 |
| SR-F10.7 | 在 DSH 内做的修改必须落回同一个数据库，且可被旧 UI 看到 |

## 四、非功能规格

| SR | 一句话 |
|---|---|
| SR-NF1 | 判定必须可复现：每条结论带命令与读数，不写「应该没问题」 |
| SR-NF2 | 不许静默降级：要么做，要么明确报错并说明限制 |
| SR-NF3 | 提示词缓存必须稳定（系统消息逐字节不变） |
| SR-NF4 | 工具参数必须严格 schema（拒绝额外键） |
| SR-NF5 | 不可信内容（网页/材料/文档正文）只当数据，不当指令 |
| SR-NF6 | 失败必须可归因：错误分流成 `not_configured` / `blocked` / `not_found` / `error` |
| SR-NF7 | 文档与代码同源：改了行为就改文档，文档里每条断言可复验 |
| SR-NF8 | 跨平台可跑（Windows 与 Linux 同一套判据） |
