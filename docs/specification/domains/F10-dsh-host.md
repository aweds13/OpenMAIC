# F10 在 DSH 里当宿主

## 域的范围

管「课件不再住在浏览器标签页里，而是住在 DSH 应用里」这件事的约束：面板要看得到、工具要读得到当前页、改完要落回同一个库。
不管写入闸怎么判（F9）、也不管检索与抓取工具本身（F5/F6）—— 只管**换宿主**带来的新增约束。

## 规格

### SR-F10.1 课程列表、页列表、单页渲染必须在 DSH 内完成

**规则**：在 DSH 里必须能走完「选课 → 选页 → 看到这一页的实际样子」三步，全程不离开 DSH 窗口、不切换应用。

**为什么是这条线**：目标不是搬页面，是换宿主。任何一个环节要把人踢回浏览器，「不维护两套」就不成立 —— 因为那一步之后就会有人开始维护两套。

**违反长什么样**：列表在 DSH 里，点开某一页却弹出浏览器标签。

### SR-F10.2 课件必须用上游渲染器原生渲染，不得自绘近似版

**规则**：slide 页必须用上游 `@openmaic/renderer` 的 `SlideCanvas` 渲染同一份 canvas 数据。不得为了省事重写一套简化渲染（用 div 拼位置、只显示标题、截成图片）。

**为什么是这条线**：近似版会在第一次上游改设计令牌时就开始漂移，而漂移是渐进的、没人报错的。画布尺寸、内边距、字号换算、主题变量全部由渲染器负责，重写一份等于复制一遍它的全部隐含假设。

**违反长什么样**：自己按 `left/top/width/height` 摆绝对定位的 div。

**当前状态：成立（2026-10-30 修复并由冒烟双向钉住）。**

### SR-F10.3 不得要求打开 Edge 或任何外部浏览器

**规则**：DSH 内的全部功能（看课件、问、改）不得依赖外部浏览器进程。需要抓网页时走本机抓取服务，不启动浏览器 UI。

**为什么是这条线**：本机的 `browse_page` 走 8730 的 Playwright 服务、被 fake-IP 拦（**不是它坏了**，是这台机器的网络环境如此）。若把「看课件」也建在浏览器进程上，同一个网络问题会同时打死两件事。

**违反长什么样**：点「预览」时 `start msedge`。

### SR-F10.4 同一份数据只能有一个真源，不得在宿主侧建影子副本

**规则**：DSH 面板与旧 Web UI 必须读同一个 PostgreSQL 库、同一批表。禁止把课程数据复制到插件目录、JSON 文件、或 DSH 的配置里当作「缓存真源」。进程内允许缓存瞬时状态（如「当前页」），但不得缓存课程内容。

**为什么是这条线**：影子副本一旦建立，两边就会各自演化，然后出现「在 DSH 里改的、旧 UI 看不到」。而这种情况的第一反应通常是「再同步一次」，于是同步逻辑本身成为新的 bug 源。

**违反长什么样**：插件启动时把课程 dump 成 `courses.json` 再读它。

### SR-F10.5 「当前页」必须在 UI 选中时立刻可被工具读到

**规则**：用户在面板里点中一页时，必须立刻有一个工具能读出 `stageId + sceneId`（连同标题与类型）。读到的必须是**刚刚点中的那一页**，不得滞后一次点击、不得返回上一次会话的值。

**为什么是这条线**：「随口问」的主语是「这页」。若模型读到的当前页是错的或空的，它会去猜，而猜测在课件这种有具体内容的对象上几乎总是错的。

**违反长什么样**：把当前页写进磁盘、下次启动时当作有效值读回来。

### SR-F10.6 「当前页」缺失时必须明说没有，不得猜测或回退到默认

**规则**：没有选中页时（DSH 刚启动、用户还没点、进程重启过），工具必须返回一个明确的「没有」并说明原因。不得回退到「第一课第一页」、不得回退到数据库里的最近一条记录、不得返回空对象让调用方自己判断。

**为什么是这条线**：「宁可空，不猜」是这条产品线的既有原则。一个善意的默认值会让模型对着一页陌生内容开始解释，而用户以为自己问的是刚才那页。

**违反长什么样**：返回 `{ ok: true, active: { stageId: 'stage-1', sceneId: 'scene-p1' } }`（默认首屏）。

### SR-F10.7 在 DSH 内做的修改必须落回同一个数据库，且能被旧 UI 看到

**规则**：DSH 侧的写入必须走与旧 UI 相同的表与字段，且必须过同一套闸（F9）。改完后刷新旧 Web UI 必须能看到这次改动。

**为什么是这条线**：这是「不维护两套」的最后一道验证。若 DSH 的写入落在别处，前面六条全白做 —— 因为用户迟早要在两个界面之间对照，而对照一旦不一致，其中一个就会被弃用。

**违反长什么样**：DSH 侧写自己的表，或写同一张表但换一套字段名。
