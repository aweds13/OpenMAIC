# F5 本地课程库检索

## 域的范围

管「把本机课程库接到 agent 手上」这件事的约束：六万条目录查得到、命中之后翻得开、查不到时说实话。
不管网页怎么抓（F6），也不管这些能力以什么口径被注册进工具表与提示词（F8）—— 只管检索与展开本身的判定。

## 规格

### SR-F5.1 检索必须支持按层级筛选（L0–L4），默认自动选层

**规则**：检索必须接受一个层级参数，取值必须完整覆盖 L0、L1、L2、L3、L4 与「自动」六种；不传时按自动选层执行。自动选层的覆盖面必须写清是「哪几层」。取值之外的输入必须被拒绝，不得被静默当成自动处理。

**为什么是这条线**：库的分布极不均匀 —— 60072 条目录里 L0 有 22505、L1 有 22048、L2 只有 242、L3 只有 232、L4 有 34438。同一个关键词在 L0 上命中的是课程名，在 L4 上命中的是一本书里的正文块；两者混在一个结果集里既排不了序，也说不清「这条命中是什么东西」。自动选层是给「不知道自己该选哪层」的常见场景一个可用默认，显式选层是给「我就要翻文档架」的场景一条直达路。

**违反长什么样**：把层级当自由字符串收下，传错拼写时悄悄按自动跑，调用方以为筛过了其实没筛。

### SR-F5.2 检索必须返回可点击定位的结构化命中，不得只回一段散文

**规则**：每条命中必须至少带：唯一标识、所属层级、标题、定位信息（课程与单元的路径，或文档的来源地址）、以及——当命中来自长文档的一个片段时——该片段在文档中的序号与总片段数，外加该文档的完整标识。返回体必须是逐条可枚举的结构，不得把所有命中揉成一段自然语言。

**为什么是这条线**：散文式返回把「到底哪一条」这个信息丢掉了 —— 模型没法引用，读者没法点开，下一步的「展开整篇」也无从下手（展开要的是一个标识，不是一句话）。片段命中不给序号与总数时，模型会把第 12 片段当成这本书的全部。

**违反长什么样**：返回「在本地课程库里找到了几门相关课程，比如程序设计、数据结构……」而没有任何标识、地址与列表结构。

### SR-F5.3 检索不得凭空编造条目；命中为空时必须明说没有

**规则**：返回的每一条命中必须来自检索结果本身，不得补全、不得推测、不得把「库里还有类似的资料」这类未命中的印象写成条目。命中为空时，返回必须显式表达「没有命中」，并同时给出可执行的下一步（放宽主题、去掉层级筛选），不得返回空列表让调用方自己猜。能力不可用与命中为空必须是两种不同的返回。

**为什么是这条线**：六万条的库「看起来什么都有」，模型很容易在空结果上顺手编一个课程名 —— 而编出来的课程名在库里不存在，读者点不开。「没查到」是一个有效答案，把它说成「没有」需要被写进规则里，否则默认行为一定是把空白填满。

**违反长什么样**：查询一个库里没有的主题，返回三条格式完全正确、但库中并不存在的条目。

### SR-F5.4 命中后必须能把整篇文档读出来，不受预览上限约束

**规则**：当检索命中来自一篇文档时，必须存在一个配套动作，用命中里给出的完整标识把该文档的正文读出来；该动作返回的正文长度不得被检索侧的预览上限约束。只提供检索而不提供展开，视为违反本条。

**为什么是这条线**：文档架上的命中只是一个片段，检索侧每条只给标题加几百字符的摘要，而库里有 3091 份可以整篇读的文档。没有展开动作，「查得到第 12 片段，但翻不开这本书」—— 检索能力等于只做了前一半。

**违反长什么样**：检索能命中，模型却只能拿着摘要回答「这本书讲了什么」。

### SR-F5.5 取全文必须支持分页/续读，且必须给出续读指针或明说读完

**规则**：取全文必须接受起始位置与本次长度两个约束，长度必须有上限。一次返回未覆盖全文时，返回体必须带上指向剩余部分的续读指针（一个位置值），且该位置值必须被下一次调用真正接受。一次返回已覆盖全文时，必须明说已读完，不得给出一个指向末尾之外的位置值。

**为什么是这条线**：正文动辄上万字符（平均 17443 字符），一次全给会直接撑爆上下文；而历史上出现过「返回里给了续读指针、却没有任何动作接收它」的死指针 —— 调用方拿到一个永远用不上的位置值，唯一的出路是从头重读。指针与接收方必须成对存在，这是分页可取的最低条件。

**违反长什么样**：分页返回里写着「还有更多」，把那个位置值传回去时却被当成非法参数拒绝；或者反过来，已经读到末尾却仍给出一个越界的位置。
