# F7 会话上下文与材料

## 域的范围

管「哪些字节进系统提示词、哪些走工具返回值、上下文满了怎么办」这条路的约束：材料能进上下文但不许打碎缓存，画像改完下次就生效，压缩要真发生而且不许空转。
不管材料本身怎么被检索与展开（F5），也不管工具以什么口径被注册（F8）—— 只管上下文的**组成与生命周期**。

## 规格

### SR-F7.1 材料/画像的修改必须在下次会话生效，不得要求重启进程

**规则**：材料索引、会话材料清单、学习画像这三类内容的读取必须发生在每次会话建立时，不得在进程启动或模块加载时读一次就缓存。只有它们的位置（路径）允许在加载时求值一次。读取失败必须表现为「这份内容不存在」，不得表现为「带着上一次的旧内容继续跑」。

**为什么是这条线**：这几份内容正是人天天在改的东西 —— 画像随学随补，材料随用随加。如果内容在加载时快照一次，那么「改了没生效」就会变成一道必须靠重启才能诊断的谜，而重启会连带丢掉所有进行中的会话。反过来，路径基本不动，把它在加载时求值一次是合理的性能取舍，且改路径本来就是个需要重启的操作。

**违反长什么样**：改完画像文件，下一轮对话里 agent 仍然按旧的学段与偏好回答，直到整台服务被重启。

### SR-F7.2 会话级材料内容不得写入系统提示词

**规则**：会话材料的名称、标识、数量、类型、抽取状态、正文字符数，以及材料正文的任何片段，都不得出现在系统消息里。材料必须以工具返回值的形态进入上下文。系统消息里关于材料的文字必须是**与本次会话装载了什么无关**的恒定文本。

**为什么是这条线**：系统消息是一个缓存单元，改一个字节就重算整条及其之后的所有消息。实测把一行材料插进一个本来没动过的会话，命中率从 99.1% 掉到 38.5%；把材料搬出系统提示词之后，连续 12 次调用命中率 99.6–100%（此前是 91.0%）。材料是会话里变化最频繁的东西，把它放进最不该变的位置，等于每加一份材料就重新付一次全量输入的钱。

**违反长什么样**：系统提示词里列出「本次会话已装载 3 份材料：某某讲义、某某课件、某某笔记」这样逐条点名的一段。

### SR-F7.3 系统消息必须在同一会话内逐字节稳定（缓存友好）

**规则**：同一会话内，只要影响内容的输入没变，系统消息必须逐字节相同。任何会被重建的片段（技能清单、材料块、课程提示块、学习者状态）都不得把「本次运行的瞬时值」拼进去。会随答题变化的块必须排在最后，其后不得再有任何块。诊断用途的指纹计算不得改变系统消息的内容，也不得因其自身失败而终止运行。

**为什么是这条线**：缓存按前缀匹配，系统消息在最前面 —— 它变一个字节，后面全部重算。而系统消息又是每轮重建的（不是缓存的对象），所以「稳定」只能靠纪律：每个块只写恒定文本，变化的部分全部下沉到工具返回值。把会变的块放最后是一条廉价的降级措施：万一它还是变了，受影响的只有它自己那一段。

**违反长什么样**：每轮把「当前时间」或「本次装载的材料数」拼进系统提示词开头，命中率随对话轮数持续下跌而无人察觉。

### SR-F7.4 原生压缩必须在预算触顶时真的发生，不得空转

**规则**：压缩被启用时，每次请求前必须评估一次上下文用量；用量越过「预算减去预留」这条线时必须真的写入一条压缩记录并把旧消息折叠掉，不得只记录一次「评估过」而什么都不做。压缩失败（摘要写不出来、找不到合法切点）不得让整轮运行失败，但必须被记进失败列表。关闭压缩时不得发生任何摘要调用，也不得改写会话记录。

**为什么是这条线**：「评估了 40 次、触发了 0 次」和「没启用」在观感上完全一样，但前者会让人以为防线在工作。压缩是否真发生必须能从记录里数出来 —— 评估次数与触发次数必须是两个独立的计数。反过来，压缩永远不该成为运行失败的原因：它是一条保护措施，保护措施自己炸掉比不保护更糟。

**违反长什么样**：上下文已经涨到预算的两倍，压缩轨迹里评估次数一路上涨而触发次数始终为 0。

### SR-F7.5 压缩预算必须按可用窗口配置，且必须大于固定开销

**规则**：压缩阈值必须来自一个显式配置的**预算**值，不得取模型目录里声明的上下文窗口。预算必须大于一次请求的固定开销（系统提示词加工具定义），且必须大到「越过它的时候压掉旧消息确实能腾出空间」。预算、预留、保留最近三段必须能分别配置；未配置时必须有默认值，默认值必须满足上面两条。

**为什么是这条线**：模型窗口是目录里的数字，有些模型标到 1M —— 拿它当阈值等于压缩永不触发，真实会话永远到不了那个数。另一头同样致命：预算低于固定开销时，每轮都会触发压缩，而摘要只能加在无法压缩的固定开销之上。实测用 6000 的预算跑四轮，输入从 23030 → 24565 → 26181 → 27831，只涨不跌 —— 压缩跑了，什么都没压掉。固定开销在这里约 23k，默认预算 150k 是它的六倍多，这个倍数关系就是这条线。

**违反长什么样**：直接拿模型元数据里的窗口当阈值，或者配一个比固定开销还小的预算，然后看着输入 token 一轮比一轮高。
