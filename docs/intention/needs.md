# needs.md — 需求清单（intention 层）

> 一页看懂：**把上游 OpenMAIC（给「听课」设计的 AI 课件生成器）改造成「自学」形态，并搬进 DSH 当宿主** ——
> 内容上屏幕、节奏由读者掌握、agent 手上有本地课程库和真浏览器、写入必须有闸、当前页要进对话。

## 意图声明（一层三件事）

- ① **改形态** —— 页面从「讲稿的附庸」变成「阅读的主体」，节奏从播放器驱动变成读者驱动。（N1–N7）
- ② **补手脚** —— agent 从「只有网络搜索」变成「能查本地课程库、能读整篇文档、能看真浏览器渲染的页面」。（N8–N14）
- ③ **换宿主** —— 从「浏览器里开 3000 端口的独立 Web 应用」变成「在 DSH 里看课件、随口问、顺手改」，不开 Edge、不维护两套。（N20–N23）

## 参考来源

- 上游：**THU-MAIC/OpenMAIC**（`https://github.com/THU-MAIC/OpenMAIC`），本仓是它的长期 fork。
- 形态参考：**纸**（密度、可读、读者掌控）而非**视频**（时间轴、自动推进）。
- 宿主参考：**DSH 插件**（`skills` + `tools` + `slots` + `webServer` 四个扩展点）。

## A. 形态：从「听课」到「自学」

- **N1** 内容必须上屏幕，不能只活在讲稿里
  - *为什么*：上游把正文写在 storyboard/讲稿，页面只放标题和几张图 —— 这是为「听老师讲」设计的。自学的读者没有那个声音。
  - *依据*：默认产出 **61 汉字/页**；同一位老师（天大《程序设计》）的真实课件实测 **352–390 字/页**，**差约 4 倍**。
  - *衍生*：引出 N2（密度）、N3（上限口径）。

- **N2** 页面密度要接近真实课件
  - *为什么*：密度太低，读者一页看到的信息量不足一屏的一半，翻页成本白付。
  - *依据*：目标区间 **350–400 汉字/页**，同时接近 1000×562.5 画布在可读字号下的物理上限。
  - *衍生*：**要更多就加页，不加每页字数** —— 超过这块画布，字号就得掉到读不清。

- **N3** 阅读节奏由读者掌握，不自动前进
  - *为什么*：上游的推进靠时间轴；没有任何动作的页会在 2 秒后「演完」自动翻走。
  - *依据*：`MIN_READING_MS = 2000`，而 350–400 字要读 **1–2 分钟** —— **差 30–60 倍**。这就是用户说的「就像放视频」。
  - *衍生*：引出 N4（假控件）、N5（翻页驱动）。

- **N4** 阅读页不许出现假控件
  - *为什么*：大播放键 / 播放暂停 / 自动播放开关在阅读页上**没有东西可播**，它们是骗人的。
  - *依据*：用户原话「我不需要这种东西」。
  - *衍生*：无。

- **N5** 翻页要能由滚轮 / 点击页面 / 方向键驱动，并且必须能关掉
  - *为什么*：阅读该由读者驱动；但在需要页内滚动的题型上，翻页手势会抢走页内滚动。
  - *依据*：滚轮去抖 **450ms** —— 否则一次轻甩翻十几页。
  - *衍生*：翻页开关必须是**可配置**且**不抢页内滚动**（见 conventions）。

- **N6** 自检页的题量必须可控，不足时必须报错
  - *为什么*：没有题量参数时永远落到 SDK 写死的 **3 题**；而 JSON 解析器会把写崩的数组砍到最后一个完整对象**当成功返回** —— 「要 8 道给 3 道」没人知道。
  - *依据*：实测工作台生成的自检页全是 3 题，而手补过的是 6/8/10 题。
  - *衍生*：无。

- **N7** 批量带走课程（PPTX / 交互页 / 整门 ZIP）必须能一次做完
  - *为什么*：原来唯一路径是「打开那门课 → Stage Header 菜单 → 逐个下载」，课一多就是一门门打开；而浏览器会拦截一个页面连续触发的多次下载。
  - *依据*：见 N7 的实现落点与实测读数（`docs/implementation/modules.md`）。
  - *衍生*：「批量」必须打成**一个 ZIP**，不能是连点 N 次。

## B. 手脚：让 agent 手上有东西

- **N8** agent 必须能查本地课程库，而不只是网络搜索
  - *为什么*：此前 agent-runtime 与本地课程库**零关联**（全目录 grep 无命中）—— 一个「AI 课件生成器」看不见自己机器上的 6 万条课程。
  - *依据*：库里有 **60072** 条课程目录（L0 22505 / L1 22048 / L2 242 / L3 232 / L4 34438）与 **3091** 份可整篇读的文档。
  - *衍生*：引出 N9（分档读）。

- **N9** 命中之后必须能展开成整篇
  - *为什么*：L4 命中只是一个**块**，没有 `read_document` 就无法展开 —— 「查得到第 12 块，但翻不开这本书」。
  - *依据*：`course_search` 的 `peek`（粗略目录）/ `full`（正文，可翻页）两档。
  - *衍生*：`read_document` 与 `course_search` 是**配套**能力，注册一个就必须注册另一个。

- **N10** 必须能看真浏览器渲染后的网页
  - *为什么*：`fetch_url` 只发一次 HTTP、拿原始 HTML，对 JS 渲染的站等于拿到空壳。
  - *依据*：实测 **75 次**抓取里 **7×404 / 3 次被反爬关键词拦 / 2 次重定向超限 / 1×403**。
  - *衍生*：引出 N11（反爬判定对象）。

- **N11** 反爬判定只许对抽取后的正文做，不许对整页 HTML 做
  - *为什么*：原本对整页 HTML 做子串匹配 —— `<script>` 里出现 `captcha` 这个字符串就整页拒绝。
  - *依据*：实测 **2 次是被裸词误伤**的。
  - *衍生*：无。

- **N12** 网页「看」与「存」必须分开
  - *为什么*：预览恒 **2000 字符**，而正文平均 **17443 字符** —— 只看预览等于只读了 **11%**；而且 `nextOffset` 是个**死指针**（没有工具接收它）。
  - *衍生*：预览用于判断值不值得存；存要走完整的取全文路径。

- **N13** 学习画像与材料库改完必须下次会话即生效
  - *为什么*：这两条是「每次运行重读」的上下文文件；如果路径在模块加载时求值一次就不再变，改完必须重启整台服务。
  - *依据*：路径加载时求值 ⇒ 内容改完下次会话就生效（这条**是设计意图，不是巧合**）。
  - *衍生*：无。

- **N14** 外部 MCP 连不上不许拖死会话
  - *为什么*：外部服务不可用是常态，不是异常。
  - *依据*：连不上只记 `failed`、**不注册工具**，绝不阻塞会话建立。
  - *衍生*：与 N15（能力注册）同一条原则的两个面。

## C. 工程底座：不骗模型、不骗自己

- **N15** 没配的能力不许注册工具，提示词里一个字都不许提它（**能力注册原则**）
  - *为什么*：「存在于工具表里但一调就失败」是模型**唯一没法理解**的一种不可用 —— 它会一直重试一个永远失败的工具。
  - *依据*：三处注册点（`lib/server/agent-runtime/runner.ts`、`app/api/chat/pi/route.ts`、`lib/chat/pi/tools/call-agent.ts`）必须**同一条口径**；其中一处曾经无条件注册，直接让上游 9 条断言红。
  - *衍生*：这条对所有新增能力是硬约束，不只是这三个工具。

- **N16** 提示词缓存必须稳定：会话材料不许进系统提示词
  - *为什么*：每登记一次材料就换一次系统提示词 ⇒ 系统消息是一个缓存单元，**改一个字节重算整条**。
  - *依据*：实测命中率 **91.0% → 连续 12 次调用 99.6–100%**。
  - *衍生*：会话材料走「工具返回值」而不是「系统提示词」。

- **N17** 原生上下文压缩必须真的会触发
  - *为什么*：上游默认开，本 fork **有意反转**为默认关。
  - *依据*：阈值必须用**预算 150k**，不能用模型窗口 —— driver 传进来的是目录里的窗口（有些是 1M），拿它当判据等于**压缩永不触发**。
  - *衍生*：无。

- **N18** 写入必须过闸，不许静默产出烂页
  - *为什么*：生成模型会写出结构洞、超载页、离题内容；静默落盘等于把问题推给读者。
  - *依据*：`generate_scene` / `patch_stage` 两条路径上的 planGate、超载闸、结构洞闸、审查闸（见 `docs/contracts/flows.md`）。
  - *衍生*：无。

- **N19** 判据必须能事后核对：真话在数据库里，不在日志里
  - *为什么*：日志说「成功了」而库里没数据的情况真实发生过。
  - *依据*：`GET /api/whoami` 报当前请求解析出的 owner、可见课程、以及 agent-runtime 里**模块加载时求值**的开关实际值。
  - *衍生*：「我改了 `.env.local` 怎么没反应」通常就是没重启，它直接告诉你进程握着什么。

## D. 换宿主：搬进 DSH

- **N20** 产品必须能在 DSH 里用：看课件、随口问、顺手改
  - *为什么*：这是本次二开的**目标本身**。不是把页面搬过去，是换宿主。
  - *依据*：DSH 插件四个扩展点（`tools` / `slots` / `webServer` / `locale`）已实测可用；两个插件共 **12** 个工具（5 个本地能力 + 7 个课程）。
  - *衍生*：引出 N21（不维护两套）、N22（当前页）、N23（顺手改）。

- **N21** 不开 Edge、不维护两套
  - *为什么*：两套 = 两份 bug、两份验证、两份文档；而 Edge 那条链路在本机被 fake-IP 拦过。
  - *依据*：本机 `browse_page` 被 fake-IP 拦（**这不是它坏了**，是网络环境事实）。
  - *衍生*：DSH 侧渲染直接用 `@openmaic/renderer` 的 `SlideCanvas({slide})`，不嵌 iframe。

- **N22** 当前页（stageId + sceneId）必须进对话上下文
  - *为什么*：用户说「这页」时，agent 必须知道是哪一页 —— 否则每句话都要人肉复述路径。
  - *依据*：`openmaic_active` 工具读插件进程内状态（DSH 重启就清空 —— **宁可空，不猜**）。
  - *衍生*：面板选中页 ⇒ `POST /dsh-openmaic/active` 写状态。

- **N23** 「顺手改」必须安全：CAS + 版面差集
  - *为什么*：改一页 = 覆盖整块 canvas；并发改会互相吞，误改会毁掉一页。
  - *依据*：写库是 CAS（`where data = $old`，旧值不匹配就拒绝并提示重读）；默认 `dryRun=true` 只算差集不写库。
  - *衍生*：差集读数（`added/removed/moved/resized/textChanged/restyled`）是改之前的判据，不是改之后的事后描述。

## 编号用法

- `N` = 需求（本层）。**删掉全部代码，这条还成立** —— 成立的才是需求。
- 追踪到规格：`N → SR`（见 `../specification/traceability.md`）。
- **本层不写技术方案**：写「为什么成立 + 依据读数 + 衍生方向」。技术方案在 `../specification/` 与 `../implementation/`。
