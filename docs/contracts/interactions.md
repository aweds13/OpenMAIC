# 契约层 · 操作契约（interactions）

> **本层是什么**：介于 `specification/`（必须做到什么）与 `implementation/`（哪个模块负责）之间的**行为链路层**。
> 它回答的问题是——**一个操作要走到哪一步才算「做完」**。
> 上游：`intention/needs.md`（N）+ `specification/traceability.md`（SR）+ `specification/conventions.md`（约定）。
> 下游：真实代码。
> 只写「行为与链路」，不写「哪个模块」（那是 implementation 的事），不贴源码。
> 范围：写在 DSH 里真的会被用到的六条操作。逐域细契约见 `domains/`。

---

## 使用方式（给 AI 的硬约束）

1. 实现任一操作前，先读本文件 + `specification/conventions.md`。
2. 每个操作的「后续」全部是必须项，不是可选项。少做一条即视为未完成。
3. 每个操作实现后，用本文件的「验收」逐条自检并回填。
4. 若某要素当前无实现（标 `⚠️ 未实现`），必须先补齐才算实现完成 —— **不许在文档里悄悄把它写成已实现**。

## OP-1 在 DSH 里看一页课件

- **入口**：DSH 主区「课件」面板。左栏课程列表 → 中栏页列表 → 右栏画布。
- **前置**：DSH 已启动；PostgreSQL 5433 可达（不可达时按 OP-6 的失败形态处理，不许白屏）。
- **输入**：无（首屏自动开第一课第一页）。后续由点击驱动。
- **后续**：
  1. 拉课程列表，每项含 `id / name / folder / scenes`（页数）。
  2. 选中课程后拉页列表，每项含 `id / order / title / type`，按 `order` 升序。
  3. 选中页后拉该页完整数据，取 `content` 与 `type`。
  4. `type === 'slide'` → 用 `SlideCanvas({ slide: content.canvas, canvasPercentage: 6 })` 原生渲染。
  5. `type !== 'slide'` → 取纯文本并按段落渲染，副行标注「类型 X · 只读文本」。
  6. 选中即写「当前页」（`stageId + sceneId + title + type`），供 OP-2 读取。
- **可逆**：只读，无副作用（唯一的写是进程内「当前页」，重启即清空）。
- **界面反馈**：三栏各自加载态；空列表要有明确文案，不许留白。
- **验收**：
  - [ ] 首屏能自动开第一课第一页，不用手点。
  - [ ] slide 页渲染出来与旧 Web UI 同页一致（同一份 canvas，不是近似版）。
  - [ ] 非 slide 页显示可读文本，且**明说**是只读文本。
  - [ ] 5433 不可达时给出可读错误（含失败原因），不是白屏或空列表。
  - [ ] ⚠️ **当前不成立**：面板读 `page.data`，宿主返回 `{id, stageId, type, title, order, content, actions}` 无 `data` 层 ⇒ slide 分支恒不成立、页面停在「取文本…」。修法：面板侧取 `page.content` / `page.type`。

## OP-2 对「当前页」随口问

- **入口**：DSH 对话输入框，用户直接说「这页讲的什么」「把这页第三段改短点」。
- **前置**：用户已在 OP-1 里选中过一页。
- **输入**：用户自然语言。
- **后续**：
  1. 模型调 `openmaic_active()` 取当前页。
  2. 有值 → 返回 `stageId / sceneId / title / type / at`。
  3. 无值 → 返回明确文案「还没有用户在面板里选过页（或 DSH 刚重启过）」。
  4. 模型按需继续调 `openmaic_page` / `openmaic_page_text` 取内容，不得凭标题猜内容。
- **可逆**：只读。
- **界面反馈**：无需（对话内完成）。
- **验收**：
  - [ ] 点中页之后立刻问，模型读到的是**刚刚点中**的那一页，不滞后一次点击。
  - [ ] DSH 重启后问，返回「没有」而不是默认首屏。
  - [ ] 当前页指向的页在库里被删了之后，后续取内容返回「没有这页」而不是崩。

## OP-3 改一页（先看差集，再落盘）

- **入口**：对当前页的自然语言指令，或 `openmaic_patch_stage` 直接调用。
- **前置**：OP-1 选中页；该页 `type === 'slide'`（非 slide 页只读，明确拒绝）。
- **输入**：`stageId` + `sceneId` + 至少一个改动（`title` / `canvasJson` / `textsJson` / `opsJson`）+ 可选 `dryRun`。
- **后续**：
  1. 读该页当前 `data` 作为 CAS 基准。
  2. 校验 canvas 形状：不是对象 / `elements` 不是数组 / 元素无 `id` / `id` 重复 / 尺寸非有限数 / `width <= 0` —— 任一命中即整批拒绝。
  3. 应用改动（`add / remove / move / resize / text / canvasField`），不认识的 op 报错并列可用值。
  4. `dryRun !== false`（默认）→ 只算差集并返回，**不写库**：`before / after / added / removed / moved / resized / textChanged / restyled`。
  5. `dryRun === false` → 带旧值 CAS 写库。旧值不匹配 → `stale`，要求重新读一遍再改。
  6. 写后报版面差集：区分「这次新引入的」「这次修掉的」「改前就有的」。
- **可逆**：不可逆（写库即改）。所以默认必须停在差集。
- **界面反馈**：面板刷新该页。
- **验收**：
  - [ ] 不传 `dryRun` 时**一定不写库**（用数据库计数或 mtime 证明）。
  - [ ] 伪造旧值 → `{ok:false, reason:'stale', rows:0}`。
  - [ ] 同值写回 → `{ok:true, rows:1}`。
  - [ ] 一批里第四条非法 → 前三条也不落盘。
  - [ ] 改前后无变化的页 → 报「这次改动没有引入新的问题」并给出改前已有条数。

## OP-4 查本地课程库

- **入口**：对话里问「我库里有没有讲 X 的」。
- **前置**：`OPENMAIC_COURSE_SEARCH_URL` 已配置。**没配就不注册这两个工具**（F8.2/F8.3）。
- **输入**：`query`（必填）+ 可选 `layer`（`auto` / `L0`–`L4`，默认 `auto`）+ 可选 `maxResults`（1–12，默认 6）。
- **后续**：
  1. 打到 8720 的 `/search`。
  2. 返回结构化命中（层级、标题、定位信息、片段）。
  3. 需要整篇时调 `read_document`（`mode: peek | full`，`limit` 上限 60000）。
  4. 404 时补 `doc:` 前缀重试一次，仍失败则明说没有。
  5. 空命中必须明说「没找到」，**不许编造**。
- **可逆**：只读。
- **界面反馈**：无需。
- **验收**：
  - [ ] 未配置时两个工具都不在工具表里，且提示词里不出现这两个名字。
  - [ ] 空命中回明确文案而不是空数组。
  - [ ] 全文超过 `limit` 时明说被截断并给总长。

## OP-5 抓一个网页

- **入口**：对话里给一个网址。
- **前置**：`OPENMAIC_BROWSE_URL` 已配置；没配不注册。
- **输入**：`url`（必填）+ `maxChars`（1000–120000，默认 40000）+ `waitMs`（0–8000，默认 1500）。
- **后续**：
  1. 服务端做 SSRF 校验（内网地址需 `ALLOW_LOCAL_NETWORKS=true` 才放行）。
  2. 打到 8730 的 `/browse`，等 JS 执行后取 DOM。
  3. 返回正文 + 来源标识（最终 URL / 状态 / 耗时）。
  4. 反爬判定只作用于正文抽取，不因为页面出现某个词就判失败。
- **可逆**：只读，且**不自动持久化**（「看」与「存」分开）。
- **界面反馈**：无需。
- **验收**：
  - [ ] 需要 JS 的页面能拿到执行后内容。
  - [ ] 内网 URL 在未开 `ALLOW_LOCAL_NETWORKS` 时被拒。
  - [ ] 抓取结果不落盘（跑完查磁盘无新增）。

## OP-6 起不来的时候怎么办

- **入口**：任意操作遇到数据库不可达 / 服务未起。
- **前置**：无。
- **输入**：无。
- **后续**：
  1. 失败归因必须是四类之一：`not_configured`（没配）/ `blocked`（被拦）/ `not_found`（没有）/ `error`（坏了）。
  2. 必须是**结构化**失败，不是抛异常、不是空数组、不是假装成功。
  3. 必须带可读原因（例如 `connect ECONNREFUSED 127.0.0.1:5433`）。
  4. 面板要把这个原因显示出来，不能只显示「加载失败」。
- **可逆**：只读。
- **界面反馈**：错误原因原文可见。
- **验收**：
  - [ ] 5433 关掉后打开面板 → 能看到 `ECONNREFUSED` 字样。
  - [ ] 8720 关掉后问课程库 → 回 `not_configured` 或带原因的 `error`，不是「没找到」（这两者含义不同）。
  - [ ] 任何失败都不许静默降级成空结果。
