# 契约层 · 动线契约（flows）

> **本层是什么**：`docs/contracts/` 的第二份。`interactions.md` 管「单个操作怎样才算做完」，本文件管「**多个操作串起来的主流程必须走通**」。
> 它回答的问题是——**用户从「想做」到「做完」，路径是否连续、数据是否流动**。
> 上游：`intention/needs.md` + `specification/traceability.md`。配套：`contracts/interactions.md`。
> 只写「链路与触发」，不写「哪个模块」（implementation 的事），不贴源码。
> 范围：四条主链路。逐域细动线见 `domains/`。

---

## 使用方式（给 AI 的硬约束）

1. 动线是**端到端**的：链上任一环断开，整条动线即不成立 —— **不允许「我这块做好了」就算完**。
2. 实现时按「触发 → 传导 → 落点」逐步核对，每一跳都必须有真实调用。
3. 每条动线给「贯通验收」—— **必须真的跑一遍**，不是看代码有没有函数。

---

## FLOW-1 主链路：在 DSH 里看到一页，改一页，看到改完的样子

> 这是「换宿主」的唯一命脉。走不通 = 换宿主不成立。

```
① 打开 DSH，进「课件」面板
        ↓  读课程列表（同一份 PG，无影子副本）
② 选一门课 → 页列表
        ↓
③ 选一页 → 该页 content 交给 SlideCanvas 原生渲染
        ↓  同时写「当前页」
④ 在对话里说「这页第三段太长，压到两行内」
        ↓  模型读 openmaic_active 拿到 stageId + sceneId
⑤ 模型读该页 → 提议改动 → openmaic_patch_stage（默认 dryRun）
        ↓  返回差集：moved 0 / resized 0 / textChanged 1 / layout delta 0
⑥ 差集看着对 → 显式 dryRun:false → CAS 写库
        ↓  旧值不匹配则整条失败，要求重读
⑦ 面板刷新该页 → 看到新样子
        ↓
⑧ 打开旧 Web UI 同一页 → 必须看到同一份新内容
```

**断点检查（每一跳都要能证伪）**：
- ②→③：页列表的 `order` 与库里的 `scene_order` 一致。
- ③：渲染的是真 `SlideCanvas`，不是近似版。**当前 ③ 断着**：面板读 `page.data` 而宿主返回无 `data` 层。
- ④：当前页必须是**刚点中**的那页。
- ⑤→⑥：不传 `dryRun:false` 时数据库零写入。
- ⑧：这条是「不维护两套」的唯一硬证据。

## FLOW-2 从「不知道在哪」到「读到那一段」

```
① 问「我库里有没有讲二次函数顶点式的」
        ↓  course_search(query, layer=auto)
② 命中若干条，带层级与定位
        ↓  选中一条
③ read_document(mode=peek) 看开头，判断是不是这篇
        ↓
④ read_document(mode=full) 取整篇；超出上限则明说截断并给总长
        ↓
⑤ 回答里引用到具体段落，不编造未读到的内容
```

**断点检查**：①② 未配置时这条动线**根本不该开始**（工具不存在，提示词不提）。④ 截断必须明说。

---

## FLOW-3 从「这个链接讲了啥」到「拿到正文」

```
① 给一个网址
        ↓  未配置 OPENMAIC_BROWSE_URL 则这条动线不存在
② SSRF 校验（内网需显式放行）
        ↓
③ 真浏览器渲染，等 JS 执行
        ↓
④ 返回正文 + 最终 URL + 状态 + 耗时
        ↓
⑤ 不落盘（「看」与「存」分开）
```

**断点检查**：③ 本机被 fake-IP 拦是环境问题，**不是这条动线坏了** —— 判据是「返回结构化失败并带原因」，不是「必须成功」。⑤ 跑完查磁盘无新增文件。

## FLOW-4 起停：从冷机到能用

```
① 起 PostgreSQL 5433（先清陈旧 postmaster.pid，否则启动失败）
        ↓
② 起 OpenMAIC 应用（dev 模式，探测 /api/whoami）
        ↓
③ 起旁挂服务：8720 课程库 / 8730 抓网页 / 8010+8000 PDF 解析 / 11434 向量
        ↓
④ 起 DSH（插件从 profile 加载，实为实体拷贝，**改了源必须重新装一次**）
        ↓
⑤ 面板能列课、能渲染、能读当前页
```

**断点检查**：
- ①→②：`postmaster.pid` 陈旧会直接起不来，且日志里只有一行 `FATAL`。
- ③：旁挂服务**全部可选** —— 缺哪个就少哪个能力，且必须表现为「工具不存在」而不是「工具在但常失败」。
- ④：插件的 profile 副本与源**是两份文件**（不是符号链接）。改了 `_tools/dsh-plugins/**` 不同步到 profile，重启加载的仍是旧版。
