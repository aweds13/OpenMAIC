# research/ —— 证据留存区

> 这里放**动手之前量到了什么**：勘察读数、行号、对比表、外部链接、当时不知道的东西。
> 它**不是五层中的任何一层**，也不承担「应该怎样」—— 那仍然只在五层里。

## 一、为什么它不在五层里

五层的每一层都回答一个读者的问题，而且**删掉代码还成立**（见 [`docs/文档架构.md`](../文档架构.md)）。研究记录不满足这两条：它随被研究对象一起漂（行号会变），且它的读者只有一个瞬间——做决定的那一刻。

它也和 `复盘/已结案结论.md` 不同：结论库收的是**事后**已经结案的坑与数；这里收的是**事前**的勘察，其中一部分结论后来被推翻过，留在这里是为了能追到「当时凭什么这么判断」。

## 二、准入三条

1. **只写实测与原文**。读数、命令、`路径:行号`、URL、提交号。不写「建议」「应该」「最佳方案」—— 那属于规格或决策。
2. **每条结论带可复核的落点**。复核者不看作者，只看那一条命令能不能重跑出同一个数。
3. **拿不准的单列一节写「不知道」**。这一节越长，文档越可信；把它删掉才是失信。

本目录仍会被 `scripts/check-layers.py` 的引用完整性检查扫到（它 `rglob` 整个 `docs/`），所以 `docs/README.md` 那条坑在这里同样成立：**别用反引号包通配符**，反引号里的 .md 会被当成真实文件去核存在性。

## 三、什么该离开这里

| 这里的某条东西 | 归宿 |
|---|---|
| 一条必须做到的行为 | `docs/specification/domains/` 下加 SR，再在 `docs/specification/traceability.md` 挂 N |
| 一条「当时选了 A 没选 B，代价是 C」 | 决策记录（ADR 形态；本仓尚无该目录，见 §五） |
| 一个模块负责什么、常量是多少 | `docs/implementation/modules.md` |
| 一个踩过的坑、一个量过的数 | `复盘/已结案结论.md` |
| 已经过期的事实 | **直接删**，不打补丁 —— 历史在 git 里 |

搬走之后在本目录留一行指针即可，不要两边都留正文（同一份事实只留一处）。

## 四、里面有什么

### `材料统一/`（8 份，一套连续的规格链）

课程材料模块的完整勘察与设计。读的顺序就是文件号：`材料统一/00-决策记录.md` 定九条方向（D1–D9）与用户硬约束，01–06 各管一层（持久化 / 工具面 / 抽取流水线 / 外部能力 / 读语义与提示词 / 业界最佳实践），07 做取舍与实施拆分。

一句话结论：**一期只做行为面收敛，不动 DDL**；工具面 5 个（`list_materials` / `read_material` / `search_materials` / `add_materials` / `organize_materials`），删除类动词恒 0；服务层拆两个，靠 import 语句当判据。

### 根级四份（各自独立）

| 文件 | 量的是什么 |
|---|---|
| `PBL架构勘察.md` | PBL 运行时为什么不落课程文档、学情为什么进不了学习状态 |

## 五、已知欠账（诚实清单）

- **材料统一的 5 工具 / 持久层 / 抽取流水线在五层里没有对应 SR**。F7 现有五条（SR-F7.1–F7.5）讲的全是上下文与压缩，不讲材料怎么存、怎么抽、怎么删。搬进本仓只是让证据跟着产品走，**规格化还没做**。
- **本仓没有决策记录目录**。`材料统一/00-决策记录.md` 的 D1–D9 是 ADR 的雏形，但缺「候选方案」与「把握程度」两段，不符合 ADR 格式。要不要立目录、要不要回溯补齐，是未决项。
- **根级四份的行号会漂**。它们分别停在提交 `918b4f0d`、`b0aa6c87`、`c14ea8db`，文首各自写了当时的提交号；复核之前先 `git diff` 那段区间，别直接信行号。
