# 自检 —— 怎么用命令证明它在正常工作（实现层）

> **给谁看**：想知道「它现在到底是不是在工作」的人。
> **只回答一件事**：一条命令 + 它应该吐出的读数。读数对不上就别猜，照 §3 分流。
>
> 邻居分工别混：
> - 端口谁起、起停脚本、生产构建、worktree、测试怎么读 → `运维.md`
> - 想确认的是**功能**有没有生效（计划冻了没、审查跑过没、练习跑过没、agent 干了什么） → 本文件
>
> 全部读数都是**实测**来的：命令跟一条期望读数，没有读数的结论一律不许写「应该」。

---

## 0. 两条读法纪律

1. **每条命令后面必须跟「期望读数原文」。** 只说「跑一下看看」等于没写。
2. **「命令能跑」不等于「功能生效」。** `200` 只证明进程活着；开关是**开还是关**要看下面的 JSON 键，
   路径上的闸有没有真的拦过要看 `agent_session_events`。

## 1. 第一站：`/api/whoami`（开关的真实值都在这里）

```bash
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:3000/api/whoami
```

期望读数：`200`。
⚠ 在 PowerShell 里**必须写 `curl.exe`**，写 `curl` 是 `Invoke-WebRequest` 的别名，`-o NUL` 会报错。

去掉 `-o NUL` 就能看全文。返回体有两层：外层 `{ ownerId, stageCount, stages, error, runtime }`，
开关全在 `runtime` 里：

| `runtime` 的键 | 它反映的环境变量 | 本部署的期望值 | 说明 |
|---|---|---|---|
| `selfStudyDefault` | `OPENMAIC_SELF_STUDY` | `true` | 页里没有讲稿、内容直接上屏（350–400 汉字/页） |
| `planGate` | `OPENMAIC_PLAN_GATE` | `true` | 计划没冻结，生成新页和修复旧页都被拒 |
| `courseAuditTool` | —（恒 `true`） | `true` | 只读审计工具在工具表里 |
| `maxConcurrent` | `OPENMAIC_AGENT_RUNTIME_MAX_CONCURRENT` | `1` | 同时只跑一场会话（代码默认 2，本部署钉 1） |
| `compactionEnabled` | `OPENMAIC_AGENT_COMPACTION_ENABLED` | `true`（本部署） | 代码默认是**关**，要显式 `= 'true'` 才开 |
| `compactionContextBudgetTokens` | `OPENMAIC_AGENT_COMPACTION_CONTEXT_BUDGET` | `400000`（本部署） | 代码默认 `150000`；阈值用**预算**不用模型窗口 |
| `learnerProfilePath` | `OPENMAIC_LEARNER_PROFILE_PATH` | 个人数据\学习画像.md | **每次运行重读**，改了不用重启 |
| `materialsDir` | `OPENMAIC_MATERIALS_DIR` | 个人数据\材料清单 | 同上 |
| `scratchpadDir` | `OPENMAIC_SCRATCHPAD_DIR` | <仓库>\data\scratchpad | 草稿纸，懒创建 |
| `planFreezeDir` | `OPENMAIC_PLAN_FREEZE_DIR` | <仓库>\data\plan-freeze | 冻结 / 审查凭据 / 已接受读数都在这 |
| `practiceDir` | `OPENMAIC_PRACTICE_DIR` | 课程与学习\练习 | 练习文件夹落这 |

★ **两种改动两种待遇**：改 `.env.local` 要**重启**才生效（环境变量在进程启动时读一次）；
改学习画像 / 材料清单**不用重启**（每次会话重读）。

## 2. 逐条自检（想确认 → 命令 → 期望读数）

### 2.1 服务活着

```bash
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:61123/dsh-openmaic/courses
```

期望读数：以 `{"ok":true,"courses":[` 开头的一段 JSON，`courses` 里每项形如
`{"id":"stage-…","name":"第 1 天 · 公共地基（Git·OOP·HTTP）","folder":"国庆二面冲刺","scenes":22}`。

拿到这个 JSON = **整条链路都通了**：宿主活着 + 插件装配了 + seam 路由通 + 库读得到。

**为什么不是 3000**：3000 上的 `.next/standalone` 是**陈旧的生产构建**（落后 101 个提交），
它只适合当「工作台本体」用；看「课在不在、能不能读」要从 61123 的 DSH 头端走。
`curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:61123/` 得到 `401` **是正常的**
（根路径要登录），别把它当宿主挂了。

各端口自己那一层的健康读数（8720 / 11434 / 8730 / 8010 / 5433）在 `运维.md` 的冷机自检八步，
这里不抄第二份。

### 2.4 审查跑过没

```bash

```

期望读数：形如 `stage-GYvpbYB_aN.review.json`。**有 = 审查闸认它有凭据**（凭据跨 run 有效）；
没有 = 这门课还没审过，≥8 页时 `patch_stage` 会被拒一次，跑 `review_course` 或带
`reviewAcknowledged` 才放行。

```json

```

有它，无状态审计就不会每次再报同一批页。

### 2.8 agent 到底干了什么（唯一取证入口）

不是日志，是 `agent_session_events` —— 每次工具调用的**入参 + 结果**都在里面。

```bash
PGPASSWORD=postgres PGCLIENTENCODING=UTF8 \
  "D:/PostgreSQL-OpenMAIC/pgsql/bin/psql.exe" -h 127.0.0.1 -p 5433 -U postgres -d postgres
```

**① 最近这场会话的每一步**（倒序 20 条）：

```sql
SELECT type, data->>'toolName' AS tool
FROM agent_session_events
WHERE session_id = (SELECT id FROM agent_sessions ORDER BY updated_at DESC LIMIT 1)
ORDER BY seq DESC LIMIT 20;
```

期望读数：`type` 是一串 `session_end / agent_end / turn_end / message_end / message_update / thinking_end …`，
带工具的那些行 `tool` 是 `patch_stage`、`generate_scene`、`read_stage` 之类。
`tool` 全空 = 这场会话一条工具都没调，那它什么也没改。

**② 工具调用分布**（一眼看出它在拿什么补什么）：

```sql
SELECT data->>'toolName' AS tool, count(*) FROM agent_session_events
WHERE type='tool_execution_end' GROUP BY 1 ORDER BY 2 DESC;
```

期望读数（本机全量实测，最新一次）：

```
        tool        | count
--------------------+-------
 patch_stage        |   571
 generate_scene     |   364
 read_stage         |   360
 grep_stage         |   174
 fetch_url          |   100
 plan_freeze        |    89
 edit_deck          |    65
 web_search         |    62
 ask_user           |    60
 scratch            |    51
 course_search      |    44
 read_stage_outline |    36
```

★ 这张表能当**设计判据**用：`patch_stage` 与 `generate_scene` 同量级，说明它不是「只会生成不会改」；
`read_stage + grep_stage` 数量大，说明它在先读后写。

**③ 写入后诊断的计数**（现在**一定会出现**，0 也写）：

```sql
SELECT data->'result'->'details'->>'coverageGapCount' AS gaps,
       data->'result'->'details'->>'planIssueCount' AS plan,
       count(*)
FROM agent_session_events
WHERE type='tool_execution_end'
  AND data->>'toolName' IN ('generate_scene','patch_stage')
GROUP BY 1,2 ORDER BY 3 DESC;
```

期望读数：`gaps` / `plan` 都是干脆的数字（`0` 是正常，`0` 也照样写一行）。
真正要看的是**有没有计数**：`gaps` 与 `plan` 两列同时为**空**，说明那次写入没跑诊断 —— 那才是问题。
本机实测分布（取前几行）：

```

------+------+-------
      |      |   468      ← 历史早于诊断落地，两列空
 0    | 0    |   179
 0    | 8    |   145

 0    | 3    |    20
```

## 3. 出问题了怎么办

| 你看到 | 是什么 | 怎么办 |
|---|---|---|
| **本轮生成失败 / `terminated`** | 那一次的上游连接被切断。**不是你的错，也不是数据坏了**；已落盘的修改都在 | 说 **「继续」** —— 会话保持可恢复（上限 5 次） |
| **`generate_scene 被拒绝：计划里没有第 N 页`** | 计划门槛在正常工作 | 先 `plan_freeze backfill` → 冻结 |
| **`patch_stage 被拒绝：计划是空的 / 还没冻结`** | 同上，**修复**也受管 | 同上 |
| **`patch_stage 被拒绝：… 超载 …`** | 超载闸在正常工作 | 它会把数字和提问摆出来，**你回答它**；它会带 `overloadAcknowledged` 再调一次 |
| `还没有跑过判据` | 练习生成了但没跑 | VS Code 打开那个文件夹 → `Ctrl+Shift+B` |
| 页面能开但**按钮没反应** | Next 16 的 dev origin 拦截（`127.0.0.1` 的 JS 被 403） | 已修在 `next.config.ts`；确认 `allowedDevOrigins: ['127.0.0.1','localhost']` 那行还在 |
| 改了 `.env.local` 没反应 | 环境变量在**进程启动时**读一次 | 重启 `_tools\openmaic\start_all.ps1` |
| **`URL is not allowed: … not on an origin previously seen in this session`** | URL 信任闸在正常工作 | **把链接贴在对话里**（一行就够），或让它先 `web_search` 那个域名 |
| `curl` 返回 `000`、退出码 `7` | 连接被拒 —— **那个端口没起**，不是白屏 bug | 先按 `运维.md` 起服务；`401` 是另一回事（见 §2.1） |
| `tsc` 报 `@openmaic/renderer` 没有导出某个类型 | 不是代码错：`packages/@openmaic/renderer/dist/` 缺 `.d.ts`，整个包退化成 `any` | 跑 `corepack pnpm run build:packages`，或补 `npx tsc --emitDeclarationOnly --declarationDir dist`，然后才是真的 0 error |

## 4. 四个读数陷阱（吃过亏，别再吃）

1. **中文写进 SQL 会报 `invalid byte sequence`** —— `psql.exe` 按 GBK 发出去。两个绕法：
   `t LIKE U&'%\65C1\767D%'`（码点转义），或把 SQL 存成 UTF-8 文件再 `psql -f`。
2. **`stageCount: 0` 不是数据丢了** —— owner 是「一个浏览器一个 cookie」的匿名身份，
   不带 cookie 的 curl 拿到的是新 anon，自然 0。要看真实课程用 §2.1 那条 seam。
3. **`git diff --stat 57fbcc4..HEAD -- packages/@openmaic` 输出为空 ≠ 上游包没动。**
   真读数是 **165 files / +14826 / −792**。`57fbcc4` 只是个祖先，路径过滤后为空只说明那段历史对不上。
   **空输出当「没动」是假绿灯。**
4. **「测试全绿」也可能是假绿灯** —— 一条在 Windows 上扫出 0 个入口却报绿的覆盖矩阵，
   和一条真通过的一模一样。判据必须自己打出「这次实际检查了几条」，**N=0 同样算失败**。

## 5. 「怎么说」—— 每个能力的调用说法与期望反应

自检回答「它是不是在工作」，这一节回答「**我怎么让它干活**」。每条给：说法的样子、去哪儿看结果、什么样的反应算正常、以及**如实说明这条闸能管到哪儿**。

> 说明：这一节的说法来自二开过程中实测过的真实对话，不是设想。已知的失败反应写在每条末尾。

### 5.1 先审计，再动手（只读，最安全）

**怎么说**：`course_audit 一下 Day 1，把超载的页告诉我`

**去哪看**：直接在对话里回一张逐页表（每页「承接率」+ 超载页）。

**怎么算正常**：它报出超载页，例如 `1 页超载（一次引入超过 49 个新块）：第 9 页《面向对象三概念…》(64)`。
真实读数：Day 1 第 9 页 novel=64；另有两页更严重（第 45 页 **242**、第 29 页 **209**）。**它只读，不改任何东西。**

★ **超载页不许被静默改掉**：`patch_stage` 碰到 novel > 49 的页会**先拒一次**，把数字摆出来，并要求先 `ask_user` 问「拆成 2–3 页 / 改写这一页 / 先不动」，拿到答复后带 `overloadAcknowledged: true` 再调。

⚠️ **这条闸的边界（如实说）**：`overloadAcknowledged` 只是「我确实问过了」的**凭据**，工具**看不到你们的对话** —— 模型硬填 `true` 而没问，闸拦不住。它能保证的是：**「静默跳过」不再可能**（要么拒，要么留下一条带 flag 的调用记录）。

### 5.2 计划冻结 —— 被拒绝是正常的

`planGate=true` 时，**计划没冻结 ⇒ 生成新页和修复旧页都会被拒**。这是故意设计，不是坏了。先 `plan_freeze` 落计划，或问用户要不要开闸。

### 5.3 自检页：题量不达标必须报错

生成自检页时给 `questionCount`。**实测坑**：不给参数就永远落到 SDK 写死的 3 题；而 JSON 解析器会把写崩的数组砍到最后一个完整对象**当成功返回** —— 「要 8 道给 3 道」没人知道。
★ 题量有**双上限且不一致**：工具 schema 收 1–30（`lib/server/agent-runtime/generation-tools.ts:126`），outline schema 上限 100（`lib/server/generation/outline-schema.ts:29`）。31–100 会绕过工具层校验。

### 5.4 练习模式：生成、跑、记错题

练习不是网页里的功能，是**磁盘上的文件夹 + 通用 runner**：

| 步 | 说法 | 产物（去哪看） |
|---|---|---|
| 生成 | 「给第 17 页出三道条件判断的练习题」 | `课程与学习/练习/<stageId>/NN-标题/`，含起始文件、`check.mjs`、`checks.json`、`README.md`、`.vscode/` |
| 跑 | 用户 `Ctrl+Shift+B`（或让 agent 跑 `check.mjs`） | 同目录 `result.json`；`practice_result` 回报 `x/y 通过` + 每条失败原文 |
| 记 | 自动 | 个人数据目录下的 学习状态.md：**「现在还做错的」**（条目形如 `- 「题目」— 第 18 页《…》，题号 q8（答 B）`）与**「已经全对（不必重复考）」** |

★ 三条硬口径：
- `check.mjs` 是**契约，别手改**；判据写成**数据**（`checks.json` 里写命令，不写代码）。
- 没跑过时 agent 必须明说「还没有跑过判据」并告诉你 `Ctrl+Shift+B`，**不许装作全过**。
- 个人数据目录下的 学习状态.md 是**机器写的，别手改**；`practice_result` 与作业/自检结果都回流到这里。

落点：`课程与学习/练习` 由 `OPENMAIC_PRACTICE_DIR` 决定，`/api/whoami` 的 `runtime.practiceDir` 会回显（见 §1）。

### 5.5 批量带走课程

「把 Day 2 整门课导出成 ZIP」。产物在浏览器下载目录。★ 必须打**一个 ZIP**，不是连点 N 次 —— 浏览器会拦截一个页面连续触发的多次下载（见 `docs/specification/domains/F4-bulk-export.md`）。

### 5.6 读网页：三道门

`browse_url` 走真浏览器。三道门依次是：**URL 信任闸**（`SSRF` 判据，见 §2.9）→ **反爬判定**（只对**抽取后的正文**做，不对整页 HTML 做）→ **存与看分开**（预览恒 2000 字符，正文平均 17443 字符 —— 只看预览等于只读了 11%）。规格见 `docs/specification/domains/F6-browser-fetch.md`。
